# 设备操作日志（DEVICE OPERATIONS LOG）

> 本文档记录我（助手）在用户真机上执行的**每一个**改动性操作。
> 只读操作（查看、ping、读文件）不强制记录；**任何写入/安装/删除/重启类操作必须记录**。
> 目的：全程可审计、可隔离、可一键回退，绝不碰用户系统文件。

---

## 一、铁律（不可违反）

1. **绝不修改、删除、覆盖任何 Apple 系统文件或用户既有文件。** 只动"我自己创建/安装"的东西。
2. **任何改动性操作，先记录到本文档的「操作台账」再执行**（至少事后立即补记）。
3. **所有我创建的文件必须落在隔离区**（见第二节），禁止散落在 `/tmp`、系统目录。
4. **命名统一带前缀 `vmq`**，便于识别与批量清理。
5. **高风险操作（安装 tweak、respring、dpkg、重启）执行前必须在设备可 SSH 恢复的前提下进行**，并向用户说明风险。
6. **每次操作后更新「当前设备状态」表。**

## 六、本会话历史记录（已全部回退，留档备查）

以下是本会话在设备上做过、**现已全部清除**的操作，留作审计：

1. **scp 传输 IPA** → `/var/mobile/VMQMonitor-v2.ipa` → 已删 ✅
2. **dpkg 安装 roothide deb** → 装入 `VMQListener.dylib`+`.plist`(注入目录)、`vmqmond`(/usr/libexec)、LaunchDaemon、dpkg 包注册 → 设备重启时未保留 + 已确认清除 ✅
3. **移动 VMQListener 到隔离区** → `/var/mobile/vmq_quarantine/` → 已删 ✅
4. **多次编译测试 dylib**（VMQMini、mini、mini2、t）→ `/tmp/` + 注入目录 → 已删 ✅
5. **写 perl 补丁脚本** → `/tmp/patchpac.pl` → 已删 ✅
6. **写禁用标记** → `.../VMQMonitorV2/listener.disabled` → 随目录已删 ✅
7. **多次 respring**（sbreload / launchctl kickstart）→ 无持久化残留 ✅
8. **本地 WSL 装 sshpass、记录 host key** → 仅影响我的 Windows 环境，未动设备 ✅

**核心结论（本会话技术发现）：** 死机根因 = Linux/WSL 与设备开源 clang-14 产出的 arm64e slice 缺版本化 PAC ABI 标记（`caps 0x0`，应为 `E USR00`），iOS 16 dyld 加载即崩。正确 hook 点为 `BBServer::publishBulletin:destinations:`。可靠修复需 Apple 官方工具链（macOS/GitHub Actions）。

## 七、一键回退手册（越狱激活状态下执行）

> 前提：设备已 SSH 可连、越狱已激活（`/var/jb` 存在）。全部用精确路径，绝不用通配符扫系统目录。

```bash
# 1. 卸载守护进程（若存在）
sudo launchctl unload /Library/LaunchDaemons/com.z010genleman.vmqmonitor.v2.vmqmond.plist 2>/dev/null

# 2. dpkg 精确卸载我们的包（只删本包文件）
sudo dpkg -r com.z010genleman.vmqmonitor.v2.runtime 2>/dev/null

# 3. 删注入目录里我们的 tweak（精确文件名）
sudo rm -f /Library/MobileSubstrate/DynamicLibraries/VMQListener.dylib
sudo rm -f /Library/MobileSubstrate/DynamicLibraries/VMQListener.plist
sudo rm -f /Library/MobileSubstrate/DynamicLibraries/VMQMini.dylib
sudo rm -f /Library/MobileSubstrate/DynamicLibraries/VMQMini.plist

# 4. 删隔离区 + 数据目录 + 工作区（全是我们自己的）
sudo rm -rf /var/mobile/vmq_work
sudo rm -rf /var/mobile/vmq_quarantine
sudo rm -rf "/var/mobile/Library/Application Support/VMQMonitorV2"
sudo rm -f  /var/mobile/VMQMonitor-v2.ipa

# 5. 验证：注入目录无 VMQ、其他 tweak 完好
ls /Library/MobileSubstrate/DynamicLibraries/ | grep -i vmq || echo "CLEAN_no_vmq"
ls /Library/MobileSubstrate/DynamicLibraries/*.dylib | wc -l   # 应仍为用户原有数量
```

> **不属于回退范围（用户自己的资产，绝不动）：**
> - `/var/mobile/ioswa-main/`（用户旧项目源码）
> - `/var/mobile/RootHidePatcher/...`（用户 RootHide Patcher 数据）
> - `/var/mobile/Library/Filza/.Trash/...`（用户自己删进回收站的）
> - TrollStore 里的 app 图标（用户在手机上自行删除）
